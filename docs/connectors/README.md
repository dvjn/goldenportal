# Connectors

A connection reads one system through a connector. Pick the page for your system to see its config, what it reads, and the fields worth knowing.

- [GitLab](gitlab.md): groups, projects, pipelines, jobs, deployments and more.
- [SonarQube](sonarqube.md): projects with their measures and quality gate.
- [Authentik](authentik.md): users and groups.
- [HTTP](http.md): any JSON API, pulled or pushed.
- [Portal](portal.md): the portal's own users, groups, blueprints and connections.
