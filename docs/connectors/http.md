# HTTP

For any system without its own connector. You define each resource: where to read it, how the system pushes it, or both.

- Pulling a JSON API: [Systems Without a Connector](../syncing.md#systems-without-a-connector).
- Having the system push: [Systems That Send Updates](../syncing.md#systems-that-send-updates).
- Objects are what the resource's `items` jq gives; the connector adds no fields.
