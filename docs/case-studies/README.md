# Case Studies

Three stages of one portal, each building on the one before. Every portal starts at the first.

- [Getting Started](getting-started.md): GitLab and AWS. A catalog of teams, repositories and the AWS resources they run on, ownership people trust, and actions for access, claiming resources, retiring repositories and new services.
- [Growing](growing.md): adds authentik, SonarQube and Kubernetes, for development and delivery. Services apart from repositories, workloads across clusters, pipelines, jobs and code quality, and upgrades opened as merge requests and tracked by a scorecard.
- [At Scale](at-scale.md): adds an org directory, an API gateway, PagerDuty and Jira, bringing the whole developer platform into one portal across business units. APIs and their consumers, databases and compliance, a database migration, incidents, postmortems and production changes, and each developer's day: Jira issues and the merge requests waiting on them.

Each one goes need, systems, catalog, getting data in, self-service, scorecards, dashboards, then the order to build it in.
